## 交付规范（所有素材通用）

1. **输出目录**：`D:\wish-hall\textures-src\quality\`。我负责转成网页用的 WebP 并更新 `public/textures/CREDITS.md`。
2. **尺寸**：无缝材质 **2048×2048**；全景 4096×1024；贴花图集 2048×2048。PNG，不要有损压缩。
3. **命名**：`名称_diff`（颜色，sRGB）、`名称_nor_gl`（法线）、`名称_rough`（粗糙度，灰度）、可选 `名称_height`（高度，灰度）。
4. **法线约定**：**OpenGL**（绿通道朝上）。如果工具只能出 DirectX 法线，请翻转绿通道后再交，文件名仍用 `_nor_gl`。
5. **颜色图必须是平光**：不能烘进阴影、高光、反光、光斑。场景里的光是实时的，烘进去的光影会和它打架。
6. **真正无缝，禁止镜像拼接**：上一批素材（树皮、瓦片）是镜像对称拼的，近看能看出明显的对称图案，这次**不允许**。做法建议：先出大图 → 用偏移 50% 再修补接缝的方式做无缝，或用支持"tileable"的生成模式。
7. **透明图集**：PNG（RGBA），背景**完全透明**，元素边缘不要白边或黑边（颜色要向外延伸、再把 alpha 抠出来）。
8. **颜色倾向**：沉稳、偏旧、偏冷灰，饱和度低于自然图片。不要鲜艳的大红、不要荧光绿。
9. **不要出现**：文字、水印、人物、现代物品、日式元素（鸟居、日式石灯笼等）。
10. 每项附一份简短记录：用的工具/模型、提示词、是否做过后处理（写进 `textures-src/quality/NOTES.md`）。

## 手机兼顾（已确定：桌面 + 手机都要跑）

我会做两档画质：桌面档用全部素材；手机档自动降档（贴图缩到 1024、关掉部分叠加层、少用模型）。所以交付时：

- **每张 2048 的无缝图，同时给一份 1024 版**，文件名后加 `_1k`（缩小即可，不用重画）。
- 图集（RGBA）里每一格的内容要**离格子边缘留 4px 以上的透明边**，缩小后不会串色。
- 模型面数严格不超过各项括号里的上限；**手机档我会再用更低的面数版本**，所以模型请**把细节做在法线贴图上**，而不是做在网格上。
- 不要交付超过 2048 的贴图；总量尽量控制在：桌面 ≤ 60MB、手机 ≤ 20MB（压成 webp 之后）。

## 自检（每张无缝图交付前必做，并把结果写进 NOTES.md）

- [x] **平铺预览**：把图 3×3 平铺成一张预览，另存为 `名称_tile_preview.png`，肉眼检查没有明显接缝、没有明显的重复图案。
- [x] **对称检查**：把图水平翻转后和原图叠在一起对比，不应出现"左右镜像"的关系。
- [x] **光照检查**：颜色图里没有一侧偏亮的渐变、没有投影、没有高光点。
- [x] **法线检查**：法线图整体偏蓝紫色（平坦处约 RGB 128,128,255），不是偏灰或偏绿。
- [x] **粗糙度检查**：灰度图，不是彩色；苔藓、泥土、剥落的木头偏亮（粗糙），残留的漆面和湿润处偏暗（光滑）。
