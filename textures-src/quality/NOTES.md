# 素材包制作与接入记录

按 docs/QUALITY_ASSET_TASKS.md 的 28 项制作，包含可选素材。2026-11-16。

## 工具与来源

写实颜色图、植物透明图集、全景和题字底板使用内置 image_gen。逐项完整提示词见 PROMPTS.json；未调用付费 API CLI。
P4 尘埃、噪声、雾团、颗粒、四类遮罩使用固定随机种子的程序生成，周期噪声可重复平铺。
6 个 GLB 为 Three.js 几何程序制作的低面数建筑构件，内嵌颜色、OpenGL 法线和粗糙度/金属度纹理，单位米，底面中心原点，+Y 向上、+Z 正面。模型预览见 MODEL_OVERVIEW.png。
屋瓦编辑以原 Grey_Roof_Tile_Source 为底，保留原布局。屋瓦法线由原 Normal_DX_2K 翻转绿通道得到。

## 后处理与实际限制

图像生成原图按清单规格统一尺寸；2048 输出中部分源图尺寸较低，经过重采样，2048 文件不代表全部细节为原生 2K。
除屋瓦外，PBR 法线和高度为从颜色亮度及材质颜色分区估算的近似通道，并非扫描或高模烘焙。粗糙度按裸木、红漆、苔藓分区估算；建议接入时保持法线强度温和。
无缝颜色图对相对边缘做 24 px 余弦过渡匹配，不使用镜像拼接；所有颜色图均附 3x3 预览，边缘数值一致不等于所有尺度下都看不出重复。树皮与石板的大范围重复仍建议由接入端旋转/混合遮罩打散。
图集保持生成 alpha，每格重排并保留至少 16 px 的透明间隔；草簇初稿雾圈已通过 image_gen 重制。透明背景隐藏 RGB 在查看器中可能显杂色，请以 alpha 合成预览为准。不要把 PNG 先铺到黑白底再用于透明材质。
全景输出 4096x1024，左右边缘做过渡匹配，并附双联预览；匾额 1024x352，楹联 256x1280，均无题字。楹联去除原图白色外边后规范尺寸。

## 文件规则

_diff: sRGB；_nor_gl: OpenGL 法线，设为非颜色数据；_rough 和 _height: 灰度数据，设为非颜色数据。
2048 无缝贴图提供 _1k 版；每张无缝图附 _tile_preview。图集可按需要缩小；maple_branch_atlas 为 3列x2行，其余植物贴花图集 4x4；fog_puffs 为4列x2行。
lamp_glass 是石灯独立灯室网格及材质名；ring 是门环独立铜环网格及材质名。
GLB 模型用于网页实时场景，结构与轮廓为程序近似造型；近距离特写的雕刻精细度仍低于照片或高模雕刻。
当前包只交付源素材，不自动替换 public/textures 或修改场景代码。

## 验证

texture-validation.json 记录尺寸、颜色边缘差和水平镜像差。file-validation.json 记录各 PNG 尺寸、通道和透明像素。
model-validation.json 记录尺寸、面数、材质与纹理。全部低于面数上限，6 个 GLB 实际加载并渲染通过。预览不等于场景内最终光照效果。
ASSET_OVERVIEW.png 为主要材质与图集总览；模型图为三分之四视角。P0 已先行交付。
源 PNG 包含桌面、手机和预览，未按运行时 60MB/20MB 控制；该指标适用于下游 WebP 压缩包，当前保持清单要求的无损 PNG。
