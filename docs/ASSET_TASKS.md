# 素材任务清单（对齐参考图：夏季晴天、树荫斑驳的许愿池）

目标：在指定时间段内，场景与参考图几乎一致；其余时间保持现有昼夜变化。
优先级：P0 = 决定"像不像"，P1 = 重要，P2 = 锦上添花。
状态栏请在交付后打勾：`[ ]` → `[x]`。

## 交付规范（所有素材通用）

- 原始文件放 `textures-src/`；我负责压缩成 WebP 输出到 `public/textures/`，并更新 `public/textures/CREDITS.md`。
- 无缝贴图要求四边可平铺，2048×2048（2K）。
- 法线贴图用 OpenGL 约定（绿通道向上），命名 `_nor_gl`。
- 命名：`名称_diff`（颜色，sRGB）、`名称_nor_gl`（法线）、`名称_rough`（粗糙度）、可选 `名称_ao` / `名称_height`。
- 带透明的图集用 PNG（RGBA），背景完全透明，边缘不要有白边或黑边。
- 模型用 GLB，单位为米，原点在底面中心，朝向 +Y 向上，贴图内嵌。
- 每个素材附：来源链接和授权（优先 CC0 / 自有版权）。

## P0 必需

### 1. 树荫光斑遮罩 `canopy_shadow`
- [x] 无缝平铺灰度图，PNG，2048×2048
- 内容：俯拍树冠透光的叶影，黑（遮光）白（透光），对比分明，叶片和空隙大小不一，不要出现规则重复的图案
- 用途：做成太阳光的"光斑遮罩"，落在草地、石头、水面上，并缓慢飘动
- 数量：1 张主图，最好再来 1 张不同尺度的（细碎叶影）用于叠加

### 2. 岩石
- [ ] 首选：带苔藓的岩石模型 5～8 块，GLB，每块 ≤ 5000 面，自带贴图（颜色/法线/粗糙度）
  - 要求：棱角分明的花岗岩，顶面有苔藓、侧面有地衣斑；大、中、小各有几块；大小约 0.3～1.2 米
- [x] 次选（没有模型时）：无缝 PBR 岩石贴图 2～3 套
  - `rock_mossy_a` / `rock_mossy_b` / `rock_lichen`（颜色、OpenGL 法线、粗糙度，最好附高度或 AO）

### 3. 地面小植物图集 `groundplants_atlas`
- [x] PNG（RGBA）图集，约 2048×2048
- 内容（每种 3～4 个不同形态，整丛）：
  - 三叶草 / 酢浆草（小圆叶）
  - 小蕨（羽状）
  - 蜂斗菜类的大叶（参考图右侧）
  - 零星白色小花（五瓣）
- [x] 苔藓草地无缝 PBR 地面贴图：`ground_mossgrass_diff / _nor_gl / _rough`，2048×2048

## P1 重要

### 4. 水底卵石
- [x] 河床卵石无缝 PBR：`riverbed_pebbles_diff / _nor_gl / _rough`
- 要求：中等大小的圆石，偏黄褐、青灰，层次丰富，有细砂缝；2048×2048
- [x] 可选：细小无缝的水面波纹法线图 `water_ripple_nor_gl`，1024×1024

### 5. 落叶和花瓣图集 `leaves_atlas`
- [x] PNG（RGBA）
- 内容：红色枫叶、橙黄枫叶、白色花瓣，每种 3～5 片，不同角度和卷曲程度，单片不要太小（≥ 256 px）

### 6. 石狐石材
- [x] 浅米色风化花岗岩无缝贴图：`fox_stone_diff / _nor_gl / _rough`，2048×2048
- 要求：偏奶白、米黄，有风化和细微裂纹；不含苔藓（苔藓由程序叠加）
- 说明：模型继续使用现有的石狐，只换石材外观
