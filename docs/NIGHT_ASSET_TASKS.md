# 夜景素材任务清单（对齐夜景参考图：月夜、深蓝青水面、阔叶地被环绕的古池）

目标：夜晚的许愿池和夜景参考图接近。其余部分（水面月光倒影、调色、岩石湿润感、暗角）只改代码，不需要素材。
状态栏交付后打勾：`[ ]` → `[x]`。

## 交付规范（与白天素材一致）

- 原始文件放 `textures-src/`；我负责压缩成 WebP 输出到 `public/textures/`，并更新 `public/textures/CREDITS.md`。
- 带透明的图集用 PNG（RGBA），背景完全透明，边缘不要有白边或黑边。
- 颜色用**正常的日光下的颜色**（不要画成夜景色、不要加蓝色调）；夜间的暗淡、低饱和由程序控制。
- 每个素材附来源和授权说明（AI 生成的写明生成工具和日期）。

## P0 必需

### 1. 阔叶地被图集 `groundcover_broadleaf_atlas`
- [ ] PNG（RGBA），2048×2048，4 行 × 4 列，每格一整丛植物
- 用途：铺在石圈外一两米内，取代现在大片平整的深色草地，是和参考图最大的差别
- 内容（每行一种，每种 4 个不同形态：大小、叶片朝向不同）：
  - 第 1 行：玉簪 / 宽卵形叶丛（叶面光滑，叶脉明显）
  - 第 2 行：虎耳草 / 细辛类（圆形或心形的小叶，叶柄细长）
  - 第 3 行：蜂斗菜幼株（圆而大的叶，比白天用的那种更小更低）
  - 第 4 行：酢浆草或常春藤类的小叶地被（成片、叶多而小）
- 要求：
  - 高度不超过 40 厘米的矮丛；视角略俯视（和游戏镜头接近，约 50°～60°俯角）
  - 叶面要有质感（光泽、叶脉），夜里月光下才会有叶片被照亮的感觉
  - 每丛底部贴着格子下边缘，左右留出空白

## P1 重要

### 2. 小白花图集 `whiteflowers_atlas`
- [ ] PNG（RGBA），1024×1024，2 行 × 4 列
- 用途：月光下零星发亮的小白花点缀（参考图里池边和草丛里有）
- 内容：
  - 第 1 行：单株五瓣小白花带叶（4 个形态）
  - 第 2 行：成簇的小白花（4 个形态，密一些）
- 要求：花瓣是纯净的白色（不要偏黄偏粉），带少量绿叶；花朵占格子的主要部分

## P2 锦上添花

### 3. 湿润岩石的法线细节 `rock_wet_nor_gl`
- [ ] 无缝 OpenGL 法线贴图，1024×1024
- 用途：夜里石头表面湿润的细碎起伏，让高光不显得塑料
- 内容：细小的水珠状凹凸和细密的颗粒，强度较弱

### 4. 去水印的夜景参考图
- [ ] `reference_night_wishing_pool.png`，不小于 2560×1440，无文字和水印
- 用途：对色（水的蓝青、植物的深绿、石头的暗灰）

## 需要你确认

- [ ] **月亮的位置**：参考图里月光倒影在池面上方偏中间。夜里月光倒影要不要固定从池子后方取（无论真实月亮在哪，总有一条亮带）？
- [ ] **萤火虫**：参考图里没有。夜里去掉，还是保留一点？
- [ ] **适用季节**：夜景地被只做夏季，还是四季通用？
