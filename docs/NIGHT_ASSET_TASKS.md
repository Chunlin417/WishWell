# 夜景素材任务清单（对齐夜景参考图：月夜、深蓝青水面、阔叶地被环绕的古池）

目标：夜晚的许愿池和夜景参考图接近。其余部分（水面月光倒影、调色、岩石湿润感、暗角）只改代码，不需要素材。
状态栏交付后打勾：`[ ]` → `[x]`。

## 交付规范（与白天素材一致）

- 原始文件放 `textures-src/`；我负责压缩成 WebP 输出到 `public/textures/`，并更新 `public/textures/CREDITS.md`。
- 带透明的图集用 PNG（RGBA），背景完全透明，边缘不要有白边或黑边。
- 颜色用**正常的日光下的颜色**（不要画成夜景色、不要加蓝色调）；夜间的暗淡、低饱和由程序控制。
- 每个素材附来源和授权说明（AI 生成的写明生成工具和日期）。

## P0 必需

### 1. 阔叶地被图集 `groundcover_broadleaf_atlas`
- [ ] PNG（RGBA），2048×2048，4 行 × 4 列，每格一整丛植物
- 用途：铺在石圈外一两米内，取代现在大片平整的深色草地，是和参考图最大的差别
- 内容（每行一种，每种 4 个不同形态：大小、叶片朝向不同）：
  - 第 1 行：玉簪 / 宽卵形叶丛（叶面光滑，叶脉明显）
  - 第 2 行：虎耳草 / 细辛类（圆形或心形的小叶，叶柄细长）
  - 第 3 行：蜂斗菜幼株（圆而大的叶，比白天用的那种更小更低）
  - 第 4 行：酢浆草或常春藤类的小叶地被（成片、叶多而小）
- 要求：
  - 高度不超过 40 厘米的矮丛；视角略俯视（和游戏镜头接近，约 50°～60°俯角）
  - 叶面要有质感（光泽、叶脉），夜里月光下才会有叶片被照亮的感觉
  - 每丛底部贴着格子下边缘，左右留出空白

## P1 重要

- [ ] PNG（RGBA），1024×1024，2 行 × 4 列

- 内容：
  - 第 1 行：单株五瓣小白花带叶（4 个形态）
  - 第 2 行：成簇的小白花（4 个形态，密一些）
- 要求：花瓣是纯净的白色（不要偏黄偏粉），带少量绿叶；花朵占格子的主要部分

# 第二批：让夜景更接近参考图

第一批（阔叶地被、小白花、湿润岩石法线、夜景参考图）已经全部接入。剩下的差距主要来自石头和植物的"形状"本身（程序生成的多面体、图片卡片），只靠调参已经很难缩小。

## 交付规范（补充）

- 3D 模型用 **GLB**，单位为米，Y 轴朝上，原点在模型**底面中心**，贴图内嵌（颜色 / OpenGL 法线 / 粗糙度，最好附 AO）。
- 面数要控制：场景里会有几十到上百个实例，同时要在手机和集成显卡上流畅。
- 颜色按正常日光下的颜色（不要做成夜景色），白天和夜里共用，夜间效果由程序处理。

## P0 必需

### 5. 岩石模型 `rocks_mossy.glb`
- [x] 8～12 块不同形状的岩石，放在**一个** GLB 里（每块是一个单独的网格，命名 `rock_01`、`rock_02`……）
- 用途：取代现在程序生成的多面体石头，组成池岸石圈
- 形状：圆润的大河石 / 花岗岩块（参考图那种，棱角被水磨圆、底部略平），**不要**尖锐的碎石
- 大小：大 3～4 块（约 1～1.4 米）、中 4～5 块（约 0.6～0.9 米）、小 2～3 块（约 0.3～0.5 米）
- 表面：顶面有成片的苔藓、侧面有地衣斑和风化痕迹，颜色是深灰 / 灰绿
- 面数：每块 ≤ 3000 三角面；贴图 2048×2048（多块可以共用一张图集）

### 6. 宽叶植物模型 `broadleaf_plants.glb`
- [x] 6～8 种低矮宽叶植物，放在**一个** GLB 里（每种一个网格，命名 `hosta_01`、`butterbur_01`、`fern_01`……）
- 用途：池边和石头脚下的近景植物（参考图里前景那些宽大、有光泽的叶子），取代现在的图片卡片
- 内容：玉簪 2 种、蜂斗菜 2 种、蕨 2 种、虎耳草或细辛 1～2 种
- 要求：
  - 每片叶子是有弯曲的真实网格（不是平面卡片），叶脉要有法线凹凸
  - 叶面略有光泽（粗糙度贴图里叶面比叶柄光滑）
  - 高度 0.3～0.6 米，每种 ≤ 2500 三角面
  - 叶片可以用带透明通道的贴图 + 简单网格，但要能从各个方向看

## P1 重要

### 7. 夜空与树冠全景图 `night_canopy_panorama.png`
- [x] 等距柱状投影（2:1），4096×2048，PNG 或 EXR
- 用途：水面的倒影（参考图里水面映出树梢和夜空）和夜间的环境反光
- 内容：从池边仰望的夜晚：上半部分是深蓝夜空和一轮月亮（位置在画面中部偏上），四周是黑色剪影的树冠和枝叶，树叶之间透出暗蓝的天空
- 要求：月亮单独做得亮一些（是唯一的亮点），其余整体很暗

### 8. 同心圆涟漪法线 `ripple_rings_nor_gl.png`
- [x] 无缝 OpenGL 法线贴图，1024×1024
- 用途：夜里水面局部的一圈圈涟漪，把月光倒影打碎成一块块亮斑（参考图里那样）
- 内容：几组大小不一的同心圆涟漪，彼此不重叠，强度较弱
